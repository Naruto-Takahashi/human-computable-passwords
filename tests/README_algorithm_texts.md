# ルール文の基準ファイルについて

| ファイル | 中身 |
|---|---|
| `algorithm_texts.json` | **現行**の文面。`make test` が照合する |
| `algorithm_texts_pathB_frozen.json` | **2026-09-26 の統一前**の文面（経路Bの凍結時点） |

## なぜ2つあるか

経路B（QLoRA ファインチューニング，全82件）のアダプタは，すべて
`algorithm_texts_pathB_frozen.json` の文面で学習している。

2026-09-26 に経路A（プロンプティング）へ移る際，ルール文の記法が族によって
逆であることが判明したため統一した。

| 族 | 統一前の `X` の意味 | 統一後 |
|---|---|---|
| `lookup` / `table_add*` | 入力の値（テーブルの添字） | `C[i]` が入力の値，`X[i] = SGM_TABLE[C[i]]` |
| `pointer` / `narrowptr` / `func_*` | 変換後の値。かつ第1文が自己矛盾 | 同上（矛盾を解消） |

> [!WARNING]
> **保存済みアダプタを再評価するときは，凍結版の文面を使うこと。**
> 現行の文面で評価すると，学習時と評価時で出題が食い違い，正解率が
> 意味を失う（CLAUDE.md の「走行中は algorithms.py を編集しない」と同じ理由）。
