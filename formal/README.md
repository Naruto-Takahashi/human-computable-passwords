# formal — Lean による形式化

> 実験で観測した性質を，機械的に検証できる形で書き留める場所
>
> 📚 [ドキュメント索引](../docs/README.md) ／ 関連: [課題の一覧](../docs/task_catalog.md)

## いまあるもの

`hcp/Hcp/Basic.lean` に**鍵の識別可能性**に関する命題を置いている。

2026-09-23 の実験で，静的な和 $`Z = (X_0 + \cdots + X_{N-1}) \bmod 10`$ では
**観測をいくら増やしても整合する鍵が1個に減らない**課題があることが分かった。
原因は「ずらし対称性」で，鍵の全マスに $`c`$ を足すと和は $`Nc \bmod 10`$ だけずれる。

その個数が $`\gcd(N, 10)`$ に等しいことを Lean で検証している。

| 足す項数 $`N`$ | Lean | ソルバー実測 |
|---:|---:|---:|
| 3 | 1 | 1 |
| 4 | 2 | 2 |
| 5 | **5** | **5** |
| 6 | 2 | 2 |

**`recover_key` に使えるのは，項数が 10 と互いに素な課題に限る**ことが機械的に確かめられる。

## 使い方

```
nix profile add nixpkgs#lean4     # 初回のみ（Lean 4.30.0）
cd formal/hcp && lake build
```

Mathlib には依存していない。核 Lean の `decide` による有限検証で閉じているため，
巨大な依存を持ち込まずにビルドできる（1秒未満）。

## 方針

**形式化のために研究を広げない。**すでに実測で確かめた命題を，
機械検証できる形で書き留めるだけに留める。
現時点で形式化しうる命題は他に2つある。

| 命題 | 内容 |
|---|---|
| 吸収律 | 一様分布は $`\mathbb{Z}_{10}`$ 上の畳み込みの吸収元（鍵が一様なら $`Z`$ も一様） |
| 偏りの期待値 | ランダムな鍵に対し $`\mathbb{E}[\sum_i p_i^2] = 0.1 + 0.9/n`$ |

いずれも Mathlib が必要になるため，着手は卒論の目処が立ってからとする。
