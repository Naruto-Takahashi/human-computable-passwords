# この報告の要旨

前回（10月13日）の報告では，$N=100$ で統制すら解けず，データ量・warmup・
学習率・容量のどれを振っても改善しなかったため，$N=100$ への拡張を一旦停止した。
今週は，その失敗が何によるのかを切り分けることから始めた。

1. **実験C3の設計（10/13）**：前回の $N=100$ の結果を並べ直すと，正解率が4つの段に
   分かれていた。そこから「学習の足がかりは鍵の偏りから生まれる」という仮説を立て，
   壁が記号の数と鍵の分布のどちらにあるかを切り分ける実験を組んだ。
2. **実験C3の実施（10/13〜10/14）**：双子の鍵とランダムな鍵で 320 run を回した。
3. **標本数の位置づけ（10/17）**：Transformer が要した観測数を，理論上の下限・
   ソルバー・原論文の攻撃と並べた（新たな学習は回していない）。
4. **関連研究の調査と先行研究の読み直し（10/18〜10/19）**：原論文の被引用を洗い，
   研究室の卒論4本・英語論文・原論文・加地らを原典と1文ずつ照合した。

用語と関数の定義は末尾の付録に記す。

## 何が分かったか

**① $N \approx 100$ の壁の主因は鍵の分布である。** 同じ $N=104$ でも，C2 の鍵の
分布なら離陸し，ランダムな分布では一度も離陸しない（72/160 対 0/80）。

**② $N=26$ での $j$ 項の成功は，小さい鍵の偶然の偏りに支えられていた。**
HCP の設計への提言としては，「$N$ を大きくするより，鍵の数字を均等にする方が
学習ベースの攻撃に効く」となる。

**③ $N$ そのものの効果は関数によって分かれる。** $f_{2,2}$ は1記号あたりのデータを
揃えると回復する（16/40 → 31/40，元の鍵は 24/40）。$f_{1,3}$ は回復しない
（元 27/40 → 双子 14/40・11/40）。後者の仕組みは未特定である。

**④ Transformer は鍵の復元手段としては弱い。** $f_{1,3}$（$N=26$）を厳密ソルバーは
100件・98秒で解くが，Transformer は8,000件では一度も離陸しない。

**⑤ 新規性は「学習ベースの評価」そのものではなく，(1) Transformer で $j$ 項が解ける
こと，(2) 離陸を決めるのが鍵の分布だと設計で特定したこと，(3) 古典的な攻撃との標本数の
比較，に置く。**

# 今週の結果

## 実験C3の発端：$N=100$ の正解率は4つの段に分かれていた

前回の実験C1-N100 の55 run を並べ直すと，検証正解率の最大値は約 0.10・0.20・0.51・
1.00 の4つの段にきれいに分かれ，中間の値が1つも無かった。答えの空間
$\mathbb{Z}_{10}$ を $\mathbb{Z}_2 \times \mathbb{Z}_5$（10で割った余りを，2で割った余りと
5で割った余りの組）に分けて読むと，4つの段は「何も解けない／mod 2 だけ解けた／
mod 5 だけ解けた／両方解けた」に当たる。

統制 $h$ では答えの偶奇が2変数 $\sigma(x_{10}) + \sigma(x_{12}) \bmod 2$ だけで決まる。
0.2 の段（mod 2 だけ解けた）に届くかどうかは，**鍵の奇数の割合の偏りで5本とも
説明できた**（偏りが 0.06〜0.08 の3本は 0.2 に届き，奇数の割合が 0.49・0.51 の2本は
0.1 に留まった）。

これを一般化して，次の仮説を立てた。

> 学習の足がかりは，出力と少数の入力変数との相関であり，それは鍵の数字の偏りから
> しか生まれない。

原論文の分布的複雑度 $r(f)=k_2+1$ は，偏りの無い鍵では $k_2+1$ 個未満の変数と出力が
無相関になる性質である。勾配法にとっては，学習の初期に手がかりとなる信号が無い
ことを意味する。

### 1変数信号 $I_1$

この足がかりの大きさを，出力と各入力変数との相互情報量の和
$I_1 = \sum_i I(z; x_i)$（bit）で測ることにした。チャレンジは一様なので，$I_1$ は
鍵の数字の分布 $p$ だけで決まり，学習なしで厳密に計算できる
（モンテカルロ200万件と一致することを確認した）。ポインタ項の位置の寄与は厳密に0で，
加算項の位置だけが寄与する。

過去の実験（C2・C2.1）の鍵ごとの離陸率と照合すると，$I_1$ はエントロピーより
よく離陸率を予測した。

| データ | 関数 | $I_1$ | エントロピー |
| :------ | :---------- | :-------------------------: | :-------------------------: |
| C2 | $f_{2,2}$ | +0.64（**+0.49, p=0.035**） | −0.38（−0.15, p=0.535） |
| C2 | $f_{1,3}$ | +0.80（**+0.72, p<0.001**） | −0.74（−0.70, p=0.001） |
| C2 | $f_{3,1}$ | +0.69（+0.46, p=0.045） | −0.69（−0.45, p=0.053） |
| C2.1 | $f_{2,2}$ | +0.68（**+0.63, p=0.004**） | −0.57（−0.48, p=0.037） |
| C2.1 | $f_{1,3}$ | +0.68（**+0.73, p<0.001**） | −0.47（−0.56, p=0.012） |
| C2.1再測 | $f_{3,1}$ | +0.48（+0.38, p=0.106） | −0.53（−0.44, p=0.057） |

: 鍵ごとの離陸率との Spearman 相関（括弧内は鍵ごとの基準線を統制した偏相関）

C2 で未解決だった $f_{2,2}$（エントロピーは基準線の統制後に消えた）が，$I_1$ では残る。

ランダムな鍵では，$N$ が大きくなるほど数字の分布が一様に近づき，$I_1$ は急速に消える。

| 関数 | $N=26$ | $N=50$ | $N=100$ |
| :---------- | :----: | :----: | :-------: |
| $f_{2,2}$ | 34% | 2.8% | **0.02%** |
| $f_{1,3}$ | 25% | 1.9% | **0.02%** |
| $f_{3,1}$ | 16% | 0.1% | **0%** |

: ランダムな鍵（各5,000本）のうち，C2 で離陸率0.5以上だった鍵の $I_1$ の中央値に届く割合

## 実験C3の設計：双子の鍵で $N$ と分布を片方ずつ動かす

ランダムな鍵で $N=26 \to 100$ にすると，**$N$ が増える**ことと，**鍵の数字の分布が
一様に近づく**ことが同時に起きる。これまでの失敗（C1 の $N=50$，C1-N100）はその
重なった結果であり，どちらが効いているかで次の方向が正反対になる。

| 壁 | 意味 | 次の方向 |
| :------------ | :---------------------------------------------- | :---------------------------------------- |
| $N$ の側 | 覚える記号が多い・1記号あたりのデータが少ない | データや埋め込みなど，学習器を強くする |
| 分布の側 | 鍵が一様に近づき $r(f)$ がそのまま効いて，足がかりが消える | 学習器を強くしても足がかりは出ない。足がかりに頼らない方法へ転換する |

: 壁の所在と，次にやるべきこと

そこで，**C2 の鍵（$N=26$）を4回並べた $N=104$ の鍵**（$\sigma'(v)=\sigma(v \bmod 26)$）を
作り，「双子」と呼ぶことにした。数字の分布は元の鍵と厳密に一致し，違うのは記号の
数だけである。学習の問題は記号の並べ替えに対して対称なので，並べ方が人工的である
ことは結果に影響しない。

| | 分布：C2 の鍵（$N=26$ 由来） | 分布：ランダムな $N=104$ の鍵 |
| :---------- | :-----------------: | :-----------------: |
| $N=26$ | ① 元の鍵 | （作れない） |
| $N=104$ | ② 双子 | ③ ランダム |

: 3つの腕。① 対 ② で $N$ の効果，② 対 ③ で分布の効果を見る

予算は2通り用意した。

1. **B1**：50,000件 × 100エポック。C2 と同一。
2. **B2**：200,000件 × 25エポック。1記号あたりの出現数を $N=26$・B1 に揃え，
   更新のステップ数（62,500）も B1 に揃える。

関数は $f_{2,2}$ と $f_{1,3}$，初期値は C2 と同じ2通り，構成も C2 と同じ
（$d_{model}=32$・2層・学習率 1e-3・warmup なし）。① は C2 の再実行であり，過去の
データに頼らず比較の相手を実験内に置いた。腕 ①② は C2 の鍵20本をすべて使い
（離陸しなかった鍵の双子も含む），③ はランダムな鍵10本とした。合計 320 run である。

**結果を見る前に，解釈を表にして決めておいた。**

| 結果 | 解釈 |
| :---------------------------------------------- | :---------------------------------------- |
| ② が ① と同じように離陸し，③ は離陸しない | 壁は分布の側。記号の数そのものは壁ではない |
| ② が B2 でだけ ① に近づく | 1記号あたりのデータ量（$N$ の側の一部）が効く |
| ② も離陸しない | 壁は $N$ の側（同じ分布の ① は離陸している） |

: 事前に決めた解釈

## 実験C3の結果：壁は分布の側にあった

10/13 16:25〜10/14 02:07 に 320 run を回した（20並列で1 run 約35分。見込みの8分は
並列時の取り合いを入れていなかった）。離陸は検証正解率の最大が 0.5 を超えた run とする。

| 腕 | $f_{2,2}$ B1 | $f_{2,2}$ B2 | $f_{1,3}$ B1 | $f_{1,3}$ B2 |
| :----------------------- | :------: | :------: | :------: | :------: |
| ① 元の鍵（$N=26$） | 24/40 | — | 27/40 | — |
| ② 双子（$N=104$） | 16/40 | **31/40** | 14/40 | 11/40 |
| ③ ランダム（$N=104$） | **0/20** | **0/20** | **0/20** | **0/20** |

: 離陸した run の数

③ は 80 run すべてが床に張り付いた（検証正解率の最大は最高でも 0.138）。② はすべての
条件で離陸する run があり，離陸した run は ① と同じく 1.0 付近まで解いた。

### ① と ② の1対1の比較

① と ② は同じ鍵・同じ初期値の run が対になる。比較の目安として，**同じ条件を2回
回しただけの ① と C2 の対応**を左端に置いた（3.1節で述べるとおり，スレッド数が
違うと同じ seed でも結果が入れ替わる）。

| | ① 対 C2（同条件） | $f_{2,2}$ B1 | $f_{2,2}$ B2 | $f_{1,3}$ B1 | $f_{1,3}$ B2 |
| :------------- | :-------: | :----: | :----: | :----: | :----: |
| 両方離陸 | 20・23 | 14 | 19 | 14 | 10 |
| ① だけ離陸 | 5・3 | 10 | 5 | **13** | **17** |
| ② だけ離陸 | 4・4 | 2 | **12** | 0 | 1 |
| 両方失敗 | 11・10 | 14 | 4 | 13 | 12 |

: ① と ② の対応表（40対）。① 対 C2 の列は $f_{2,2}$・$f_{1,3}$ の順

同じ条件の再実行でも 40対中 7〜9対が入れ替わり，その向きは両側に均等に割れる。
$f_{1,3}$ の「① だけ 13・17 対 ② だけ 0・1」はこれを大きく超える一方向の差である。
$f_{2,2}$ B2 の「② だけ 12 対 ① だけ 5」は逆向きに偏る。

### 事前の解釈表に当てはめると

| 問い | 結果 | 読み |
| :------------------- | :------------------------ | :------------------------------------------ |
| ② 対 ③（分布の効果） | 72/160 対 0/80 | **壁は分布の側。** 予算を4倍にしてもランダムな分布は一度も動かない |
| ① 対 ②，$f_{2,2}$ | B1 で下がり，B2 で ① 以上に戻る | 「② が B2 でだけ ① に近づく」に当たる。1記号あたりのデータ量で説明できる |
| ① 対 ②，$f_{1,3}$ | B1・B2 とも約半分に下がり，戻らない | 事前の3行のどれにも当たらない。**$N$ そのものの効果が残る** |

: 事前の解釈表との対応

$f_{1,3}$ の双子は，離陸するならどちらの予算でも ① と同じ時期に離陸し（離陸エポックの
中央値は ① 12，② B1 11.5，② B2 は B1 換算で約12），その時期を過ぎると最後まで
動かない。予算の残りを使い切れずに落ちているのではない。鍵の単位で見ると，
$f_{1,3}$ で双子が離陸する8本は B1・B2 で同じ顔ぶれで，すべて元の鍵でも離陸する
鍵だった。$N$ が増えると，元で離陸していた鍵の約半分が落ちる。

### 考察と限界

1. **$N \approx 100$ の壁の主因は鍵の分布である。** C1（$N=50$）と C1-N100 の失敗は，
   記号が増えたことよりも，ランダムな鍵の数字が均等に近づいたことによる。
2. **学習器を強くする方向（データ・容量・学習率）では，ランダムな $N=100$ の鍵は
   解けない見込みが高い。** ③ は予算を4倍にしても床から動かず，前回3つの軸が
   効かなかったことと整合する。
3. **B2 は1記号あたりの出現数と同時に，データの重複の少なさも変えている**（20万件を
   25回 対 5万件を100回）。$f_{2,2}$ の ② B2 が ① を上回ったのはこちらの効果かもしれない。
   $N=26$ の B2 を回していないので，① 側に同じ上積みがあるかは分からない。
4. **$f_{1,3}$ で $N$ の効果が残る理由は未特定である。** 埋め込みが区別すべき記号が
   4倍になること自体か，関数の形との組み合わせかは，この設計では分けられない。
5. ③ は鍵10本である。「ランダムな分布では離陸しない」は 0/80 で強いが，まれに偏った
   鍵が離陸する可能性（C1-N100 の統制では5本中1本が離陸した）は否定しない。

## 標本数の位置づけ：Transformer の観測数を理論・ソルバーと比べる

論文化の際に必ず問われる「Transformer が使った 50,000件は，HCP の安全性の主張や
既存の攻撃と比べて多いのか少ないのか」に答えるため，既存の結果と理論式から比較表を
作った（新たな学習は回さず，ソルバーの所要時間だけを1条件ずつ測った）。観測数は，
攻撃者が見たチャレンジと応答の組の数である。

| 量 | $f_{2,2}$ $N=26$ | $f_{2,2}$ $N=104$ | $f_{1,3}$ $N=26$ | $f_{1,3}$ $N=104$ |
| :------------------------ | :----------------: | :----------------: | :----------------: | :----------------: |
| 鍵が一意に定まる観測数 | 約33 | 約120 | **100** | 約120 |
| 厳密ソルバー（本研究） | 40件で打切 | 400件で打切 | **100件・98秒** | 400件で打切 |
| CSP ソルバー（原論文） | 100件・40分 | 1万件でも不可 | 100件・53分 | 1万件でも不可 |
| 統計的攻撃の下限 $N^{s(f)}$ | 133 | 1,061 | 676 | 10,816 |
| ガウス消去攻撃 $N^{k_1+1}$ | 17,576 | 1,124,864 | 676 | 10,816 |
| Transformer：離陸しない | 8千件 0/20 | **16万件 0/20** | 8千件 0/20 | **16万件 0/20** |
| Transformer：離陸する | 4万件 15/20 | 16万件 31/40 | 4万件 11/20 | 16万件 11/40 |

: 鍵の復元に要する観測数の比較

注意点は次のとおりである。出所は，上の行から順に実験13，本研究のソルバー
（`info_limit.py`），原論文の付録C，原論文の $s(f)$，原論文の付録G.2，C1・C3 である。

1. 「鍵が一意に定まる観測数」は，$f_{1,3}$・$N=26$ の 100 だけが実測（鍵1本）で，
   $f_{2,2}$・$N=26$ の約33は比例則（$1.1 \sim 1.25N$）からの推定，$N=104$ は外挿である。
2. 「打切」は3分以内に終わらなかったことを指す。原論文の CSP ソルバーは2.5日で打ち切っており，
   $N=100$ は10,000件でも解けていない。
3. $N=104$ の Transformer の「離陸する」は双子の鍵だけである。ランダムな鍵は離陸しない。
4. Transformer の観測数は学習に使った件数（データの8割）であり，同じ観測を繰り返し
   学習している（B1 は100エポック，B2 は25エポック）。
5. $N^{s(f)}$ は $\tilde{\Omega}$ の中身であり，定数と対数因子を落とした桁の目安である。
3. 原論文の CSP ソルバーは汎用品で計算機も違うため，所要時間は直接比べられない。
   比べられるのは「何件で復元できたか」である。

### 読み

1. **Transformer は鍵の復元手段としては弱い。** $f_{1,3}$（$N=26$）では，厳密ソルバーが
   100件・98秒で鍵を一意に決めるのに対し，Transformer は8,000件では一度も離陸せず，
   40,000件でも離陸は約6割である。少なくとも**80倍以上**の観測が要る。
2. **原論文の安全性の主張とは矛盾しない。** Transformer が離陸した40,000件は，
   $N^{s(f)}$ の60倍（$f_{1,3}$）〜300倍（$f_{2,2}$）にあたる。HCP を「破った」のではなく，
   下限よりはるかに多い観測でようやく学べている。
3. **経路Cの貢献は攻撃の強さではなく，勾配学習が何に支えられているかの特定にある。**
   ソルバーは鍵の分布に関係なく制約を解くが，Transformer は鍵に偏りがある場合にしか
   離陸しない（C3 ③）。
4. **$N=104$ で比べるべき相手はガウス消去攻撃である。** CSP 型のソルバーは $N$ に対して
   指数的に重くなるが，ガウス消去は多項式時間で，必要件数が鍵の分布に依らない。
   $f_{1,3}$（$N=104$）では約1万件で鍵が求まる見込みであり，Transformer が160,000件でも
   動かないランダムな鍵もこれで解ける。ただし実装して実測はしていない。

## 研究の枠組み

HCP（人間計算可能パスワード）とは，ユーザーが記憶する秘密の数表（以下「鍵」，各要素は0〜9の整数）と，暗算できる程度の簡単なアルゴリズムを使い，ランダムな入力（チャレンジ）から出力（レスポンス）を計算する認証方式である。本研究では，この「鍵をLLMがどこまで当てられるか／使いこなせるか」を測定するベンチマークとして再定義して扱っている。鍵と乱数シードから未知の問題を無限に生成できるため，事前学習データに答えが混入していないという利点がある。

研究は3つの経路で進めている：

1. 経路A（in-context推論）：LLMの重みは一切更新せず，プロンプトの中にいくつかの入出力example（チャレンジ→レスポンスの組）を見せて，その場で鍵を推論・逆算させる。

2. 経路B（ファインチューニング）：大量の入出力ペアを使い，追加学習（QLoRA）でLLMの重みに鍵とその使い方を覚え込ませる。従来の機械学習モデル（CNN）と同じ枠組みで，研究室の先行研究と直接比較できる。7月に一区切りとしたが，8月の指導教員の指示「より難しい関数の探索」を受けて再開している。

3. 経路C（1から学習する Transformer）：事前学習を持たない小さな Transformer エンコーダを，先行研究の CNN と同じデータ・同じ評価で学習させる。**先行研究との差分が self-attention だけになる**ため，アーキテクチャの効果だけを取り出せる。2026年9月に着手した。

3つの関係は次節の表に整理した。

## 実験の基本設定

1. **モデル**：ローカルで動かせる Qwen2.5-3B-Instruct を用い，QLoRA（4bit量子化＋LoRA）で追加学習している。

2. **Bパラダイム**：経路Bで採用している学習・評価形式。プロンプトはFew-shot例を含まない最小形式（「Input: [...] に対する Z を答えよ」のみ）とし，従来のCNNと同じ「入力→出力の直接対応のみを学習する」条件に揃えている。

3. **paradigm=pure**：教師データの形式。学習の答え（教師completion）は `{"answer": <値>}` というJSON1行のみで，計算の途中経過や鍵の値は一切含まない。損失もこの1行にしかかからず，プロンプト側（ルールの説明文を含む）には一切かからない。

4. **held-out評価**：学習に使ったデータとは別に生成した，一度も見せていない入力で正解率を測定する。学習用と評価用でチャレンジの乱数シード空間を分離しており，重複しないことを保証している。

5. **学習条件**：学習1000件・5エポックを標準としている（1000件という数は，比較対象であるCNNの学習データ量に揃えたもの）。

## 記号の定義（原論文の記法）

### 秘密写像 σ（＝本研究で「鍵」と呼んでいるもの）

$$
\sigma : [n] \to \mathbb{Z}_{10}
$$

$[n]$ は $1$ から $n$ までの自然数の集合 $\{1, 2, \dots, n\}$，$\mathbb{Z}_{10}$ は10で割った余りの同値類，すなわち1桁の整数の集合 $\{0, 1, \dots, 9\}$ である。つまり $\sigma$ は，画像や文字など n 個のオブジェクトから10進数の数字への写像であり，ユーザーはこれを暗記する。

### チャレンジ C

$$
C_i \in [n]^k
$$

$C_i$ は $i$ 番目のチャレンジ，$[n]^k$ は集合 $[n]$ の直積を $k$ 回とったもの，すなわち $[n]$ の要素を並べた長さ $k$ の列の全体である。

ここでの $k$ は「1回のチャレンジで提示するオブジェクトの個数」＝チャレンジ長であり，関数 $f$ が受け取る入力の個数と一致する（原論文は一般形を $f : \mathbb{Z}_{10}^k \to \mathbb{Z}_{10}$ と書く）。**この $k$ は，後述する関数族のパラメータ $k_1$・$k_2$ とは別のものである**。両者には $k = 10 + k_1 + k_2$ という関係がある。

### レスポンス

$$
f(\sigma(C))
$$

$\sigma(C)$ は，チャレンジ $C = (C_1, C_2, \dots, C_k)$ の各要素に秘密写像 $\sigma$ を適用したもの，すなわち $(\sigma(C_1), \sigma(C_2), \dots, \sigma(C_k))$ である。サーバは公開されたチャレンジを提示し，ユーザーは暗記した $\sigma$ で数字に直してから関数 $f$ を暗算し，その結果を答える。

原論文で確認した内容である（2026-08）。

**本研究のパラメータと原論文の設定の対応**


| | 本研究 | 原論文 |

| $n$（$\sigma$ のマス数） | 10 または 26 | 説明用の例示として n=26 を挙げるが，実験・公開チャレンジの主軸は n=50・100。著者自身は n=100 を約2時間で暗記したと報告 |

**Stage（情報開示レベル）**：0=ヒントなし，1=$\sigma$開示・ルール非開示，2=ルール（関数 $f$）は開示するが $\sigma$ は非開示，3=ルール開示＋$\sigma$の一部を開示。本研究は主にStage 2で行っている。

## 人間計算可能関数 $f_{k_1,k_2}$

原論文が提案する関数族は次の形をしている。

$$f_{k_1,k_2}(x_0, x_1, \dots, x_{9+k_1+k_2})
   = x_j + \sum_{i=10+k_1}^{9+k_1+k_2} x_i \pmod{10}
$$

$$
\text{ここで}\quad j = \left( \sum_{i=10}^{9+k_1} x_i \right) \bmod 10
$$

入力変数は $10 + k_1 + k_2$ 個＝チャレンジ長 $k$ である。入力ベクトルは $x = (\sigma(C_0), \dots, \sigma(C_{9+k_1+k_2}))$，すなわちチャレンジに $\sigma$ を適用した後の数字列である。$k_1$ 個の項を足して添字 $j$ を作り（＝どこを見るかを決める），参照した値 $x_j$ にさらに $k_2$ 個の項を足して答えとする。先頭の10個（$x_0$〜$x_9$）は動的参照の飛び先として確保される（$j$ が $\bmod 10$ で決まるため）。

本研究の主対象 `func_22` は $(k_1, k_2) = (2, 2)$ の場合にあたる。

## 安全性パラメータ $s(f)$

原論文は，攻撃者が $\sigma$ を復元するのに必要な観測数が $m = \tilde{\Omega}(n^{s(f)})$ であると示しており，その指数 $s(f)$ を次のように定義している。

$$
s(f) = \min\left\{ \frac{r(f)}{2},\ g(f)+1 \right\}
$$

$r(f)$ は**分布的複雑度**，すなわち出力に偏り（相関）を生じさせないために固定しなければならない最小の入力変数数であり，提案関数では $r(f_{k_1,k_2}) = k_2 + 1$ である。$g(f)$ は**線形化変数数**，すなわち完全な線形方程式に退化させるために固定しなければならない最小の入力変数数であり，$g(f_{k_1,k_2}) = \min\{ k_1, 10\}$ である。これを代入すると

$$
s(f_{k_1,k_2}) = \min\left\{ \frac{k_2+1}{2},\ k_1+1,\ 11 \right\}
$$

となり，`func_22` では $s(f) = 1.5$ である。

この $r(f)$ の定義「出力に偏りを生じさせないために固定すべき変数数」が $k_2+1$ であることは，**最後の加算項 $k_2$ が出力分布の偏りを打ち消す役割を担っている**ことを意味する。実験2 の結果は，この構造が実際に効いていることを示している（[experiment_index.md](../experiment_index.md)）。

| **A** | ✓ | ✓ | ✗ | Qwen3.5 ＋ in-context（推論のみ） |

経路C は先行研究との差分が **self-attention だけ**である。経路A・B は事前学習という
交絡を同時に持ち込むため，アーキテクチャの効果を切り分けられない。
小川さんら(2025) §5.4 は将来課題の筆頭に「attention 系・Transformer 系の評価」を挙げて
おり，経路C はその課題に直接対応する。

## 難易度の分解と，扱っている関数の定義

本命の関数 `func_22` の難しさを3要素に分解し，簡単な要素から単独で検証できるよう診断用の関数を作成している。`sgm[i]` は鍵の i 番目，`X[i]` はチャレンジの i 番目を表す。

**難易度を3要素に分解した診断用の関数**


| 名称 | 計算式 | 分離している要素 |
| :--- | :--- | :--- |
| `lookup_k` | $Z = \text{sgm}[X_0]$ | ① 記憶のみ |
| `table_add_k` | $Z = (\text{sgm}[X_0] + \text{sgm}[X_1]) \bmod 10$ | ① + ② 合成 |
| `pointer_k` | $j = (\text{sgm}[X_{10}] + \text{sgm}[X_{11}]) \bmod 10$<br>$Z = \text{sgm}[X_j]$ | ① + ③ 動的参照 |
| `func_22`（本命） | $j = (\text{sgm}[X_{10}] + \text{sgm}[X_{11}]) \bmod 10$<br>$Z = (\text{sgm}[X_j] + \text{sgm}[X_{12}] + \text{sgm}[X_{13}]) \bmod 10$ | ① + ② + ③ |
| `table_add3_k` | $Z = (\text{sgm}[X_0] + \text{sgm}[X_1] + \text{sgm}[X_2]) \bmod 10$ | ① + ②（静的3項．統制） |
| `narrowptr_k_m1` | $j = (\text{sgm}[X_{10}] + \text{sgm}[X_{11}]) \bmod 1 = 0$<br>$Z = (\text{sgm}[X_j] + \text{sgm}[X_{12}] + \text{sgm}[X_{13}]) \bmod 10$ | 文面は動的・実質静的（統制） |
| `func_pow` | $Z = (\text{sgm}[X_{10}]^4 + 2\,\text{sgm}[X_{11}]^3 + 3\,\text{sgm}[X_{12}]^2 + 4\,\text{sgm}[X_{13}]) \bmod 10$ | 小川さんら Table 6 の no-j 統制そのもの |


「動的参照」とは，計算の途中で求めた数値 j を使ってチャレンジの j 番目の要素を新たに読みに行き，その値をさらに鍵で変換する，という間接参照の構造を指す。

## これまでの結果の要点（今回の報告の前提）

> [!WARNING]
> **7〜8月の結論の多くは撤回・保留になっている。**原因は関数の難しさではなく
> 測定系だった（9月13日の報告）。ここには現時点で保っている結論だけを書く。

### 測定について（経路B で判明したこと）

1. **正解率が偶然水準付近でも「学習できない」とは言えない。**与えた学習予算の中で
   学習が**離陸したか**を測っていた。同じ関数・同じ鍵でもデータの引き方を変えると
   10.2% が 100% になる。
2. **1条件1run では何も言えない。**離陸は run ごとに起きるか起きないかであり，
   平均±標準偏差はその混合比を報告しているにすぎない。**離陸率**で報告する。
3. **偶然水準（10%）と比べてはいけない。**鍵ごとの**最頻値基準線**と比べる。
4. **鍵を揃えずに関数を比べてはいけない。**「$n=10$ で動的参照の有無が 100% 対 34%」
   という7月の統制実験は鍵を揃えていない比較であり，撤回した。

### 関数と難しさについて

5. ①記憶と②合成は，十分なデータ量があれば学習できる（未知の組み合わせでも汎化する）。
6. **③動的参照（$j$ 項）は，self-attention を与えると解ける。**経路C で
   $N=26$・50,000件の $f_{2,2}$ が検証 1.0000・試験 0.9998 に達した。小川さんらの CNN は
   同条件で最大 0.6858・平均 0.2872 であり，**「$j$ 項が構造的な壁」という
   先行研究の中心的結論はアーキテクチャ依存の主張に弱まる**。
7. **難しさは理論指標 $s(f)$ の順に並ばない（むしろ逆順）。**離陸率は
   $f_{3,1}$（$s=1.0$）4/20 ＜ $f_{1,3}$（$s=2.0$）11/20 ＜ $f_{2,2}$（$s=1.5$）15/20。
8. **離陸するかは，多くの場合鍵 $\sigma$ そのものの性質で決まる。**鍵5本 × 初期値4通りに
   分解すると，$f_{3,1}$ では鍵が分散の 100%，$f_{1,3}$ では 85% を説明する。
9. **崩壊点は観測密度にある。**鍵サイズを 26 → 50 にすると $f_{2,2}$ の離陸率は
   15/20 → 3/20 に落ちる（統制は 20/20 → 16/20）。データ量も 10,000件では
   $j$ 項ありが全条件 0/20 で，50,000件で初めて離陸する。
10. **鍵の効果は再現するが，$k_2$ 順に強まるという予測は反証された。**鍵20本に
    増やしても離陸率はC1（鍵5本）とほぼ一致する一方，エントロピーとの相関強度は
    $f_{1,3}$（$k_2=3$）$\approx$ $f_{3,1}$（$k_2=1$）$\gg$ $f_{2,2}$（$k_2=2$）で，
    予測した順序には並ばない（実験C2）。
11. **鍵の偏りが離陸率に効くかは，鍵ごとの基準線を統制して判定する必要がある。**
    鍵の最多重複（最頻値の出現回数）は，鍵ごとの基準線（最頻値予測器の正解率）
    自体と強く相関しており（$f_{3,1}$ で $\rho=0.85$），固定しきい値
    （検証正解率 >0.5）による離陸判定だけを見ると，基準線のシフトを経由した
    見かけの相関が混ざる。基準線を統制して相関を取り直すと，$f_{3,1}$・
    $f_{1,3}$ では**エントロピーの方が残り**，最多重複は消える（p=0.459／0.058）。
    $f_{2,2}$ はどちらの指標も統制後は非有意で，未解決である（実験C2）。
12. **基準線を実際に揃えた鍵集合でも，3関数すべてでエントロピーが離陸率に
    効き，最多重複は消える。**基準線を学習なしで計算し，関数ごとに適切な帯
    （$f_{2,2}$・$f_{1,3}$ は幅0.01，$f_{3,1}$ は基準線の分散が大きいため
    0.125〜0.165）に揃えた鍵20本を選んで検証した（実験C2.1）。帯内の残差
    基準線を統制してもエントロピーは残る（$f_{2,2}$ p=0.009，$f_{1,3}$
    p=0.038，$f_{3,1}$ p=0.050）が，最多重複は帯内ではほぼ無関係になる
    （$f_{3,1}$ で素のp=0.739）。$f_{3,1}$ は低基準線の帯では離陸する鍵が
    1本も無く（検証不能だった）高基準線側に帯を広げて初めて分散が得られた。

### 記号の数 $N$ と鍵の分布について（経路C）

13. **$N=26$ で $d_{model}=128$ の崩壊は warmup で直るが，これは $j$ 項との相性に
    限られる。**統制は warmup の有無に関わらず不変だった。
14. **$N=100$ の統制は，データ量・warmup・学習率・容量のいずれを振っても解けなかった。**
    5鍵中4鍵は一度も学習が立ち上がらなかった（実験C1-N100）。
15. **$N \approx 100$ の壁の主因は，記号の数ではなく鍵の数字の分布である。**C2 の鍵を
    4回並べた双子の鍵（$N=104$，数字の分布は元と同一）は 72/160 が離陸し，同じ
    $N=104$ のランダムな鍵は予算を4倍にしても 0/80 だった。$N=26$ での $j$ 項の成功は，
    小さい鍵に偶然生じる偏りに支えられていた（実験C3）。$N$ そのものの効果は関数に
    よって分かれ，$f_{2,2}$ は1記号あたりのデータを揃えると消えるが，$f_{1,3}$ では残る。
16. **離陸のしやすさは，出力と1変数との相関の総量 $I_1$（学習なしで厳密に計算できる）
    で最もよく予測できる。**C2 で未解決だった $f_{2,2}$ でも基準線の統制後に残る。
    ランダムな鍵では $N$ とともに急速に消え，$N=100$ で $N=26$ の離陸鍵の水準に届く鍵は
    0.02% しかない。

### 情報量の下限について（経路A の基準線）

17. 鍵が一意に定まる最小観測数 $m^*_{\text{info}}$ は $n$ に**比例**する
    （$m^*/n \approx 1.1\text{〜}1.5$）。決めているのは1観測が制約する鍵マス数で，
    $s(f)$ には依らない。**$j$ 項ありの方が最小である**（1観測が5マスを制約するため）。
    したがって「$j$ 項ありが失敗した」を情報不足では説明できない。

## 用語（本研究で独自に使っているもの）

学習一般の用語（損失・エポック・LoRA など）は
[llm_training_basics.md](../llm_training_basics.md) の用語表にある．

| 用語 | 意味 |
|---|---|
| 鍵 / $\sigma$ | 利用者が記憶する秘密の数表．長さ $n$，各要素は 0〜9 |
| チャレンジ / $C$ | 認証のたびに提示される $k$ 個の位置の並び |
| レスポンス / $Z$ | チャレンジに対して暗算で返す1桁の数字 |
| 鍵シード（`key_seed`） | どの鍵を使うかを決める乱数シード |
| データシード（`data_seed`） | どのチャレンジを引くかを決める乱数シード．鍵は変えない |
| 衝突確率 | $\sum_i p_i^2$．答えの分布を完全に知った上で独立に当てずっぽうしたときの正解率．**偶然水準（10%）ではなくこれと比べる** |
| 最頻値基準線 | 最も多い答えを常に返す戦略の正解率．計算能力ゼロでも出る下限 |
| 離陸 | 学習が動き出し，検証損失が急に落ちること．本研究では検証損失 0.15 を下回った最初のエポックで判定する |
| 床 | 正解率が偶然水準付近に張り付き，条件間の差が識別できない状態 |
| 離陸率 | 同一条件を反復したうち離陸した run の割合．**経路C の主指標** |
| 初期化シード（`init_seed`） | 重みの初期値を決める乱数シード．鍵シードと分けて振る |
| $m^*_{\text{info}}$ | 鍵が一意に定まる最小観測数．情報量の下限 |
| 動的参照 | 参照する位置そのものを計算して決めること（$X_j$ の $j$ を入力から作る） |
| 静的参照 | 参照する位置が固定されていること（$X_0$, $X_{12}$ など） |
