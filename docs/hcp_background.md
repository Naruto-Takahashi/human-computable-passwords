## 研究の枠組み

HCP（人間計算可能パスワード）とは，ユーザーが記憶する秘密の数表（以下「鍵」，各要素は0〜9の整数）と，暗算できる程度の簡単なアルゴリズムを使い，ランダムな入力（チャレンジ）から出力（レスポンス）を計算する認証方式である。攻撃者は認証のやりとり（チャレンジとレスポンスの組）を盗み見て，鍵を求めるか，次のチャレンジへの答えを当てようとする。

本研究は，この攻撃を**勾配学習**で行ったとき（チャレンジからレスポンスを予測するモデルを観測から学習させたとき），その成否が何で決まるかを調べる。研究室では4代にわたり MLP・LSTM・BiLSTM・CNN で同じ問いを扱ってきた。本研究は Transformer を使い，成否が**関数**よりも**個々の鍵の数字の偏り**で決まることを示そうとしている。

研究は3つの経路で始めたが，2026年10月30日に経路Cを主軸にし，経路A・Bを凍結した。

1. **経路C（主軸）**：事前学習を持たない小さな Transformer エンコーダを，先行研究の CNN と同じ形のデータで1から学習させる。**先行研究との差分が self-attention だけになる**ため，学習器の効果を取り出せる。2026年9月に着手した。

2. 経路A（凍結）：LLM の重みを更新せず，プロンプトに入出力例を見せてその場で鍵を推論させる。学習の枠組みも目標も先行研究の枠の外にあるため凍結した。鍵が一意に定まる最小観測数（情報量の下限）と厳密ソルバーは，古典的な攻撃との比較に引き継ぐ。

3. 経路B（凍結）：LLM（Qwen2.5-3B）を QLoRA で追加学習させる。事前学習という交絡を持ち込み，学習器の差を切り分けられないため凍結した。ここで得た測り方の規則（離陸率で報告する・鍵ごとの基準線と比べる，など）は経路Cでそのまま使っている。

3つの関係は「学習器の3分解」の節の表に整理した。

## 実験の基本設定（経路C）

1. **モデル**：Transformer エンコーダ（埋め込み次元 32・2層・4ヘッド・FFN 128，先頭に置いた分類用トークンの出力から答えを読む）。パラメータ数は約3万（$N=30$ で 29,642）。チャレンジの各記号（$\sigma$ の何番目か）を埋め込みに通して入力する。

2. **データ**：鍵を1本決め，チャレンジを一様に50,000件引いて答えを計算する。8:1:1 に分けて訓練・検証・試験に使う（検証・試験は各5,000件）。

3. **学習**：100エポック，バッチ64，学習率 $`10^{-3}`$（warmup なし）。CPU で並列に回す（モデルが小さく，GPU でも速くならないことを実測した）。

4. **離陸の判定**：検証正解率の最大が 0.5 を超えた run を「離陸した」とする。条件ごとに鍵と初期値を何通りか振り，**離陸率**で報告する。

5. **鍵と初期値**：鍵の乱数シードと重みの初期値の乱数シードを分けて振る。解析の単位は鍵とする。

## 記号の定義（原論文の記法）

### 秘密写像 σ（＝本研究で「鍵」と呼んでいるもの）

$$
\sigma : [n] \to \mathbb{Z}_{10}
$$

$[n]$ は $1$ から $n$ までの自然数の集合 $\{1, 2, \dots, n\}$，$`\mathbb{Z}_{10}`$ は10で割った余りの同値類，すなわち1桁の整数の集合 $\{0, 1, \dots, 9\}$ である。つまり $\sigma$ は，画像や文字など n 個のオブジェクトから10進数の数字への写像であり，ユーザーはこれを暗記する。

### チャレンジ C

$$
C_i \in [n]^k
$$

$`C_i`$ は $i$ 番目のチャレンジ，$[n]^k$ は集合 $[n]$ の直積を $k$ 回とったもの，すなわち $[n]$ の要素を並べた長さ $k$ の列の全体である。

ここでの $k$ は「1回のチャレンジで提示するオブジェクトの個数」＝チャレンジ長であり，関数 $f$ が受け取る入力の個数と一致する（原論文は一般形を $`f : \mathbb{Z}_{10}^k \to \mathbb{Z}_{10}`$ と書く）。**この $k$ は，後述する関数族のパラメータ $`k_1`$・$`k_2`$ とは別のものである**。両者には $`k = 10 + k_1 + k_2`$ という関係がある。

### レスポンス

$$
f(\sigma(C))
$$

$\sigma(C)$ は，チャレンジ $`C = (C_1, C_2, \dots, C_k)`$ の各要素に秘密写像 $\sigma$ を適用したもの，すなわち $`(\sigma(C_1), \sigma(C_2), \dots, \sigma(C_k))`$ である。サーバは公開されたチャレンジを提示し，ユーザーは暗記した $\sigma$ で数字に直してから関数 $f$ を暗算し，その結果を答える。

**本研究のパラメータと原論文の設定の対応**


| | 本研究 | 原論文 |

| n | m=50 | m=100 | m=1000 | m=10000 |
| :-----: | :------: | :------: | :------: | :------: |
| 26 | 23.5時間 | 40分 | 10分 | 2分 |
| 30 | HARD | UNSOLVED | 10分 | 20秒 |
| 50 | HARD | HARD | UNSOLVED | 7時間 |
| 100 | HARD | HARD | HARD | UNSOLVED |

**攻撃者モデル**：原論文の Password Unforgeability game（Definition 2）は *"The adversary is given the function f … and is shown the challenges"* と定める。関数 $f$ は既知で鍵 $\sigma$ だけが秘密という，ケルクホフスの原理に立った設定である。経路Cの Transformer はこの攻撃者のうち，**$f$ の知識を使わず，チャレンジとレスポンスの組だけから学ぶ**攻撃者にあたる。CSP ソルバーやガウス消去は $f$ を使う攻撃者であり，本研究ではこれらを古典的な攻撃として比較の相手に置く。

## 人間計算可能関数 $`f_{k_1,k_2}`$

原論文が提案する関数族は次の形をしている。

$$f_{k_1,k_2}(x_0, x_1, \dots, x_{9+k_1+k_2})
   = x_j + \sum_{i=10+k_1}^{9+k_1+k_2} x_i \pmod{10}
$$

$$
\text{ここで}\quad j = \left( \sum_{i=10}^{9+k_1} x_i \right) \bmod 10
$$

入力変数は $`10 + k_1 + k_2`$ 個＝チャレンジ長 $k$ である。入力ベクトルは $`x = (\sigma(C_0), \dots, \sigma(C_{9+k_1+k_2}))`$，すなわちチャレンジに $\sigma$ を適用した後の数字列である。$`k_1`$ 個の項を足して添字 $j$ を作り（＝どこを見るかを決める），参照した値 $`x_j`$ にさらに $`k_2`$ 個の項を足して答えとする。先頭の10個（$`x_0`$〜$`x_9`$）は動的参照の飛び先として確保される（$j$ が $\bmod 10$ で決まるため）。

本研究では主に $`(k_1, k_2) = (2, 2), (1, 3), (3, 1)`$ の3つ（`func_22`・`func_13`・`func_31`）を扱う。どれもチャレンジ長は14である。

## 安全性パラメータ $s(f)$

原論文は，攻撃者が $\sigma$ を復元するのに必要な観測数が $m = \tilde{\Omega}(n^{s(f)})$ であると示しており，その指数 $s(f)$ を次のように定義している。

$$
s(f) = \min\left\lbrace \frac{r(f)}{2},\ g(f)+1 \right\rbrace
$$

$r(f)$ は**分布的複雑度**，すなわち出力に偏り（相関）を生じさせないために固定しなければならない最小の入力変数数であり，提案関数では $`r(f_{k_1,k_2}) = k_2 + 1`$ である。$g(f)$ は**線形化変数数**，すなわち完全な線形方程式に退化させるために固定しなければならない最小の入力変数数であり，$`g(f_{k_1,k_2}) = \min\lbrace k_1, 10\rbrace`$ である。これを代入すると

$$
s(f_{k_1,k_2}) = \min\left\lbrace \frac{k_2+1}{2},\ k_1+1,\ 11 \right\rbrace
$$

となり，`func_22` では $s(f) = 1.5$ である。

この $r(f)$ の定義「出力に偏りを生じさせないために固定すべき変数数」が $`k_2+1`$ であることは，**最後の加算項 $`k_2`$ が出力分布の偏りを打ち消す役割を担っている**ことを意味する。ただしこれは鍵の数字が一様に分布するときの性質で，ランダムに引いた鍵では近似的にしか成り立たない（次節）。

## 鍵の偏りと1変数信号 $`I_1`$

チャレンジは一様に引かれるので，各位置の数字 $`D_i = \sigma(x_i)`$ は鍵の数字の分布 $p$（数字 $d$ が鍵に占める割合 $`p_d`$）に独立に従う。$p$ が一様なら，$`k_2+1`$ 個未満の位置の数字を知っても答え $z$ の分布は変わらない。ところが $n=26$ 程度の鍵をランダムに引くと，ある数字が5個あり別の数字が0個，といった偏りが必ず生じ，1つの位置の数字だけからでも答えがわずかに読めるようになる。

その総量を**1変数信号**と呼ぶ。

$$
I_1 = \sum_{i} I(z;\ D_i)
$$

$`I(z; D_i)`$ は答えと位置 $i$ の数字との相互情報量（bit）である。$`I_1`$ は $p$ だけから学習なしで厳密に計算できる。経路Cでは，$`I_1`$ が大きい鍵ほど離陸しやすく（実験C2・C2.1・C3），$`I_1`$ を0にした鍵では離陸しなかった（実験C5）。同じ鍵の数字を付け替えて $`I_1`$ だけを上げると離陸した（実験C6）。

- **弱い鍵**：$`I_1`$ が大きく，学習攻撃が離陸する鍵。ランダムに引くと $n$ とともに急速に減る
- **そろえた鍵**：0〜9 を同じ個数ずつ持つ鍵（$n$ は10の倍数）。$p$ が厳密に一様で $`I_1=0`$。鍵の空間は減る（$n=30$ で約 99.7 bit から 81.9 bit）

## 難易度の分解と，扱っている関数の定義

本命の関数 `func_22` の難しさを3要素に分解し，簡単な要素から単独で検証できるよう診断用の関数を作成している。`sgm[i]` は鍵の i 番目，`X[i]` はチャレンジの i 番目を表す。

**難易度を3要素に分解した診断用の関数**


| 名称 | 計算式 | 分離している要素 |
| :--- | :--- | :--- |
| `lookup_k` | $`Z = \text{sgm}[X_0]`$ | ① 記憶のみ |
| `table_add_k` | $`Z = (\text{sgm}[X_0] + \text{sgm}[X_1]) \bmod 10`$ | ① + ② 合成 |
| `pointer_k` | $`j = (\text{sgm}[X_{10}] + \text{sgm}[X_{11}]) \bmod 10`$<br>$`Z = \text{sgm}[X_j]`$ | ① + ③ 動的参照 |
| `func_22`（本命） | $`j = (\text{sgm}[X_{10}] + \text{sgm}[X_{11}]) \bmod 10`$<br>$`Z = (\text{sgm}[X_j] + \text{sgm}[X_{12}] + \text{sgm}[X_{13}]) \bmod 10`$ | ① + ② + ③ |
| `table_add3_k` | $`Z = (\text{sgm}[X_0] + \text{sgm}[X_1] + \text{sgm}[X_2]) \bmod 10`$ | ① + ②（静的3項．統制） |
| `narrowptr_k_m1` | $`j = (\text{sgm}[X_{10}] + \text{sgm}[X_{11}]) \bmod 1 = 0`$<br>$`Z = (\text{sgm}[X_j] + \text{sgm}[X_{12}] + \text{sgm}[X_{13}]) \bmod 10`$ | 文面は動的・実質静的（統制） |
| `func_pow` | $`Z = (\text{sgm}[X_{10}]^4 + 2\,\text{sgm}[X_{11}]^3 + 3\,\text{sgm}[X_{12}]^2 + 4\,\text{sgm}[X_{13}]) \bmod 10`$ | 小川さんら Table 6 の no-j 統制そのもの |


「動的参照」とは，計算の途中で求めた数値 j を使ってチャレンジの j 番目の要素を新たに読みに行き，その値をさらに鍵で変換する，という間接参照の構造を指す。

## 8月の指示（動的参照の拡張）と，追加した関数（経路Bの記録）

8月に指導教員から「人間計算可能性を少し犠牲にしても，動的参照構造を増やす方向でLLMの限界を探る」という指示があり，共有された資料（8/1）で挙げられていた候補のうち，優先度の高い3種類を実装した。いずれも本命の `func_22`（動的参照が1本）を出発点に，**動的参照の本数や繋ぎ方を変えた**ものである。

### pointer_chain（深さ方向・直列に反復）

$$\begin{aligned}
j &= (\text{鍵}[X_{10}] + \text{鍵}[X_{11}]) \bmod 10 \\
j &\leftarrow \text{鍵}[X_j]
   &&\text{… これを（深さ$-1$）回くりかえす} \\
Z &= \text{鍵}[X_j]
\end{aligned}
$$

同じ操作「指した先を見て，その値が示す位置をまた指す」を繰り返す。深さ1は既存の `pointer_k` と一致する。**足し算を含まない**（$`k_2=0`$）のは，深さの効果だけを取り出すためである。

### dualptr（並列・独立な2本）

$$\begin{aligned}
j_1 &= (\text{鍵}[X_{10}] + \text{鍵}[X_{11}]) \bmod 10 \\
j_2 &= (\text{鍵}[X_{12}] + \text{鍵}[X_{13}]) \bmod 10
     &&\text{… $j_1$ とは無関係に決まる} \\
Z   &= (\text{鍵}[X_{j_1}] + \text{鍵}[X_{j_2}]) \bmod 10
\end{aligned}
$$

動的参照を2本に増やすが，**互いに依存しない**。2箇所を別々に見に行って足す形なので，反復（前の結果を次の入力にする）は含まない。資料では「最大候補（私の本命）」と位置づけられていた。

### recptr（直列・依存あり）

$$\begin{aligned}
j_1 &= (\text{鍵}[X_{10}] + \text{鍵}[X_{11}]) \bmod 10 \\
j_2 &= (\text{鍵}[X_{j_1}] + \text{鍵}[X_{12}]) \bmod 10
     &&\text{… $j_1$ の参照結果が $j_2$ の計算に入る} \\
Z   &= (\text{鍵}[X_{j_2}] + \text{鍵}[X_{13}]) \bmod 10
\end{aligned}
$$

2本目のポインタ $`j_2`$ を求めるのに1本目の参照結果 $`\text{鍵}[X_{j_1}]`$ を使うため，**参照同士に依存関係がある**。`func_22` の依存を一段強めた形にあたる。`pointer_chain` と似ているが，**各段で新しい項（$`X_{12}`$，$`X_{13}`$）を足す**点が決定的に異なる（不動点に落ちない理由．[experiment_index.md](experiment_index.md) の実験2）。

**8月に追加した3つの関数の比較**


| 名称 | 動的参照の本数 | 参照どうしの関係 | 末尾の足し算 |
| :-------------- | :----------: | :--------------: | :----------: |
| func_22（基準） | 1本 | — | あり |
| pointer_chain | 深さ分（直列） | 前の結果が次の入力 | **なし** |
| dualptr | 2本 | 独立（依存なし） | あり |
| recptr | 2本 | 依存あり | あり |


3つとも実験済み（実験2・3）。

なお `dualptr`・`recptr` はいずれも末尾に足し算があり（$`k_2 \gt 0`$），足し算のない `pointer_chain`（$`k_2 = 0`$）とそのまま比べると「動的参照の構造」と「足し算の有無」が交絡する。そこで**動的参照1本＋足し算**の基準線として，`func_22` の鍵10マス版（`func_22_k10`）を用意した。`func_22` は本来 $n = 26$ だが，$n = 26$ では動的参照の有無に関わらず崩壊して差が見えないため（実験1），深さラダーと同じ $n = 10$ に揃えている。

## これまでの結果の要点（今回の報告の前提）

> [!WARNING]
> **7〜8月の結論の多くは撤回・保留になっている。**原因は関数の難しさではなく
> 測定系だった（9月13日の報告）。ここには現時点で保っている結論だけを書く。

### 測定について（経路B で判明したこと）

1. **正解率が偶然水準付近でも「学習できない」とは言えない。**与えた学習予算の中で
   学習が**離陸したか**を測っていた。同じ関数・同じ鍵でもデータの引き方を変えると
   10.2% が 100% になる。
2. **1条件1run では何も言えない。**離陸は run ごとに起きるか起きないかであり，
   平均±標準偏差はその混合比を報告しているにすぎない。**離陸率**で報告する。
3. **偶然水準（10%）と比べてはいけない。**鍵ごとの**最頻値基準線**と比べる。
4. **鍵を揃えずに関数を比べてはいけない。**「$n=10$ で動的参照の有無が 100% 対 34%」
   という7月の統制実験は鍵を揃えていない比較であり，撤回した。

### 関数と難しさについて

5. ①記憶と②合成は，十分なデータ量があれば学習できる（未知の組み合わせでも汎化する）。
6. **③動的参照（$j$ 項）は，self-attention を与えると解ける。**経路C で
   $N=26$・50,000件の $`f_{2,2}`$ が検証 1.0000・試験 0.9998 に達した。小川さんらの CNN は
   同条件で最大 0.6858・平均 0.2872 であり，**「$j$ 項が構造的な壁」という
   先行研究の中心的結論はアーキテクチャ依存の主張に弱まる**。同じ鍵・同じデータで
   小川さんらの CNN を回し直すと，$`f_{2,2}`$ で解けた鍵は CNN 1/20・Transformer 19/20 で，
   学習器の差は鍵をそろえても残る（実験C7）。
7. **難しさは理論指標 $s(f)$ の順に並ばない（むしろ逆順）。**離陸率は
   $`f_{3,1}`$（$s=1.0$）4/20 ＜ $`f_{1,3}`$（$s=2.0$）11/20 ＜ $`f_{2,2}`$（$s=1.5$）15/20。
8. **離陸するかは，多くの場合鍵 $\sigma$ そのものの性質で決まる。**鍵5本 × 初期値4通りに
   分解すると，$`f_{3,1}`$ では鍵が分散の 100%，$`f_{1,3}`$ では 85% を説明する。
9. **崩壊点は観測密度にある。**鍵サイズを 26 → 50 にすると $`f_{2,2}`$ の離陸率は
   15/20 → 3/20 に落ちる（統制は 20/20 → 16/20）。データ量も 10,000件では
   $j$ 項ありが全条件 0/20 で，50,000件で初めて離陸する。
10. **鍵の効果は再現するが，$`k_2`$ 順に強まるという予測は反証された。**鍵20本に
    増やしても離陸率はC1（鍵5本）とほぼ一致する一方，エントロピーとの相関強度は
    $`f_{1,3}`$（$`k_2=3`$）$`\approx`$ $`f_{3,1}`$（$`k_2=1`$）$`\gg`$ $`f_{2,2}`$（$`k_2=2`$）で，
    予測した順序には並ばない（実験C2）。
11. **鍵の偏りが離陸率に効くかは，鍵ごとの基準線を統制して判定する必要がある。**
    鍵の最多重複（最頻値の出現回数）は，鍵ごとの基準線（最頻値予測器の正解率）
    自体と強く相関しており（$`f_{3,1}`$ で $`\rho=0.85`$），固定しきい値
    （検証正解率 >0.5）による離陸判定だけを見ると，基準線のシフトを経由した
    見かけの相関が混ざる。基準線を統制して相関を取り直すと，$`f_{3,1}`$・
    $`f_{1,3}`$ では**エントロピーの方が残り**，最多重複は消える（p=0.459／0.058）。
    $`f_{2,2}`$ はどちらの指標も統制後は非有意で，未解決である（実験C2）。
12. **基準線を実際に揃えた鍵集合でも，3関数すべてでエントロピーが離陸率に
    効き，最多重複は消える。**基準線を学習なしで計算し，関数ごとに適切な帯
    （$`f_{2,2}`$・$`f_{1,3}`$ は幅0.01，$`f_{3,1}`$ は基準線の分散が大きいため
    0.125〜0.165）に揃えた鍵20本を選んで検証した（実験C2.1）。帯内の残差
    基準線を統制してもエントロピーは残る（$`f_{2,2}`$ p=0.009，$`f_{1,3}`$
    p=0.038，$`f_{3,1}`$ p=0.050）が，最多重複は帯内ではほぼ無関係になる
    （$`f_{3,1}`$ で素のp=0.739）。$`f_{3,1}`$ は低基準線の帯では離陸する鍵が
    1本も無く（検証不能だった）高基準線側に帯を広げて初めて分散が得られた。

### 記号の数 $N$ と鍵の分布について（経路C）

13. **$N=26$ で $`d_{model}=128`$ の崩壊は warmup で直るが，これは $j$ 項との相性に
    限られる。**統制は warmup の有無に関わらず不変だった。
14. **$N=100$ の統制は，データ量・warmup・学習率・容量のいずれを振っても解けなかった。**
    5鍵中4鍵は一度も学習が立ち上がらなかった（実験C1-N100）。
15. **$N \approx 100$ の壁の主因は，記号の数ではなく鍵の数字の分布である。**C2 の鍵を
    4回並べた双子の鍵（$N=104$，数字の分布は元と同一）は 72/160 が離陸し，同じ
    $N=104$ のランダムな鍵は予算を4倍にしても 0/80 だった。$N=26$ での $j$ 項の成功は，
    小さい鍵に偶然生じる偏りに支えられていた（実験C3）。$N$ そのものの効果は関数に
    よって分かれ，$`f_{2,2}`$ は1記号あたりのデータを揃えると消えるが，$`f_{1,3}`$ では残る。
16. **離陸のしやすさは，出力と1変数との相関の総量 $`I_1`$（学習なしで厳密に計算できる）
    で最もよく予測できる。**C2 で未解決だった $`f_{2,2}`$ でも基準線の統制後に残る。
    ランダムな鍵では $N$ とともに急速に消え，$N=100$ で $N=26$ の離陸鍵の水準に届く鍵は
    0.02% しかない。
17. **既存の鍵では，1次の信号と2次の信号（2つの位置の組で初めて現れる信号）を分けられない。**
    ランダムに引いた鍵の偏りは「一様からどれだけ離れているか」の1本の軸でしか変わらず，
    両者の順位相関は $`|\rho| = 0.93\text{〜}1.00`$ だった（実験C4）。
18. **鍵の数字の偏りを取り除くと，学習攻撃は離陸しない。**$N=30$ のそろえた鍵は
    $`f_{2,2}`$・$`f_{1,3}`$ とも 0/30 鍵で，全60 run が偶然水準から動かなかった。同じ予算で
    偏りの大きい鍵は 27/30 鍵が離陸した（実験C5）。この予算では，鍵の偏りは離陸の必要条件である。
19. **ヒストグラムの形を変えず，数字の付け替えだけで $`I_1`$ を上げると離陸する。**同じ鍵から
    $`I_1`$ の低い版（約 0.002）と高い版（約 0.010）を作ると，$`f_{1,3}`$ で高い版は 15/15 鍵，
    低い版は 5/15 鍵が離陸し，結果の分かれた10対はすべて高い版だけが離陸した（実験C6）。
    効いているのは形ではなく，数字の値が mod 10 の足し算に対してどう並ぶか（低い次数の信号）である。
20. **鍵の効き方は学習器によらず，学習器は弱さの境目を動かす。**同じ鍵の CNN でも，ばらつきの
    78% は鍵から来て（初期値は1%），$`I_1`$ の高い鍵ほど伸びる（基準線を統制した偏相関 0.65）。
    CNN の境目は $`I_1`$ がおよそ 0.03〜0.04 で，Transformer（0.01 付近）より高い（実験C7）。

### 情報量の下限について（経路A の基準線）

21. 鍵が一意に定まる最小観測数 $`m^*_{\text{info}}`$ は $n$ に**比例**する
    （$`m^*/n \approx 1.1\text{〜}1.5`$）。決めているのは1観測が制約する鍵マス数で，
    $s(f)$ には依らない。**$j$ 項ありの方が最小である**（1観測が5マスを制約するため）。
    したがって「$j$ 項ありが失敗した」を情報不足では説明できない。

## 用語（本研究で独自に使っているもの）

学習一般の用語（損失・エポック・LoRA など）は
[llm_training_basics.md](llm_training_basics.md) の用語表にある．

| 用語 | 意味 |
|---|---|
| 鍵 / $\sigma$ | 利用者が記憶する秘密の数表．長さ $n$，各要素は 0〜9 |
| チャレンジ / $C$ | 認証のたびに提示される $k$ 個の位置の並び |
| レスポンス / $Z$ | チャレンジに対して暗算で返す1桁の数字 |
| 鍵シード（`key_seed`） | どの鍵を使うかを決める乱数シード |
| データシード（`data_seed`） | どのチャレンジを引くかを決める乱数シード．鍵は変えない |
| 衝突確率 | $`\sum_i p_i^2`$．答えの分布を完全に知った上で独立に当てずっぽうしたときの正解率．**偶然水準（10%）ではなくこれと比べる** |
| 最頻値基準線 | 最も多い答えを常に返す戦略の正解率．計算能力ゼロでも出る下限 |
| 離陸 | 学習が動き出し，正解率が急に上がること．経路C では検証正解率の最大が 0.5 を超えた run（経路B では検証損失 0.15 を下回った最初のエポック） |
| 床 | 正解率が偶然水準付近に張り付き，条件間の差が識別できない状態 |
| 離陸率 | 同一条件を反復したうち離陸した run の割合．**経路C の主指標** |
| 台地・中間・解けた | 実験C7 で導入した run の3状態．検証正解率の最大が 0.40 未満・0.40 以上 0.80 未満・0.80 以上．CNN の途中の値を完全な解と区別するため |
| 付け替え | 鍵の数字を 0〜9 の並べ替え $\pi$ で書き換えること（$`\sigma' = \pi \circ \sigma`$）．同じ数字の位置とヒストグラムの形を保ち，$`I_1`$ を動かす |
| 初期化シード（`init_seed`） | 重みの初期値を決める乱数シード．鍵シードと分けて振る |
| 1変数信号 / $`I_1`$ | 答えと各位置の数字との相互情報量の総和．鍵の数字の偏りから学習なしで計算できる |
| 弱い鍵 | $`I_1`$ が大きく，学習攻撃が離陸する鍵 |
| そろえた鍵 | 0〜9 を同じ個数ずつ持つ鍵．$`I_1=0`$ |
| $`m^*_{\text{info}}`$ | 鍵が一意に定まる最小観測数．情報量の下限 |
| 動的参照 | 参照する位置そのものを計算して決めること（$`X_j`$ の $j$ を入力から作る） |
| 静的参照 | 参照する位置が固定されていること（$`X_0`$, $`X_{12}`$ など） |
