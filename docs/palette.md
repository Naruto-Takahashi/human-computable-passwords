## 役割への割り当て

### 系列色（カテゴリ，明地）

> [!IMPORTANT]
> **正本のチャート色だけでは系列が2つしか作れない。**灰（SolidGray）は
> 彩度が 0 で「灰色に見える」ため系列色に使えず，Yellow 400 は明るすぎて
> 明度帯を外れる。使えるのは Blue 系の1つと Yellow 600 の2つである。
> 本研究の図は関数4本を並べるので**2色を拡張した**（下表の「拡張」）。
> 拡張分は正本に無い値なので，**由来と検証結果をここに残す**。

| 枠 | 明地 | 暗地 | 出所 |
|---|---|---|---|
| 1 | `#7096F8` | `#5580FC` | **Blue 400**（正本） |
| 2 | `#D2A400` | `#B08A00` | **Yellow 600**（正本）。暗地は明度帯に入れるため暗くした |
| 3 | `#41C2A8` | `#35A98A` | 拡張（翠）。正本に無い色相 |
| 4 | `#A98CE0` | `#9179DC` | 拡張（紫）。正本に無い色相 |

**順序は固定し，系列が減っても詰めない。**5本目が要るときは色を増やさず，
面を分ける（small multiples）か「その他」にまとめる。

### 連続値（ヒートマップなど）

正本の Blue ランプをそのまま使う。**明→暗の単一色相**で，相対輝度は
単調に減る（0.872 → 0.674 → 0.320 → 0.161 → 0.045 → 0.008）。

| 段 | 値 |
|---|---|
| 1 | `#E8F1FE`（Blue 50） |
| 2 | `#C5D7FB`（Blue 200） |
| 3 | `#7096F8`（Blue 400） |
| 4 | `#3460FB`（Blue 600） |
| 5 | `#0017C1`（Blue 900） |
| 6 | `#000060`（Blue 1200） |

**枡の中に数値を書くヒートマップでは 1〜3段目までに止める。**濃いインク
（SolidGray 800）とのコントラストは 11.1 / 8.7 / **4.5** で，3段目がちょうど
下限 4.5:1 に当たる。4段目（Blue 600）まで使うと **2.5:1** まで落ちて読めない。
数値を書かない図（塗り分けだけ）なら 6段すべて使ってよい。

| 段 | 濃いインクとのコントラスト | 白文字とのコントラスト |
|---|---:|---:|
| 1 `#E8F1FE` | 11.1 | 1.1 |
| 2 `#C5D7FB` | 8.7 | 1.5 |
| 3 `#7096F8` | **4.5** | 2.8 |
| 4 `#3460FB` | 2.5 | **5.0** |

### 図の地の色・線・文字

| 役割 | 値 | 出所 |
|---|---|---|
| 図の地 | `#FFFFFF` | 紙面に合わせる（画面向けは背景 Standard `#F8F8FB`） |
| 目盛り線 | `#CCCCCC` | SolidGray 200 |
| 軸・補助線 | `#999999` | SolidGray 400 |
| 図中の文字（主） | `#333333` | SolidGray 800 |
| 図中の文字（副） | `#626264` | Label |

### 状態

Success / Error / Red は**状態を表すときだけ**に使い，系列色に流用しない。
使うときは色だけにせず，記号か語を添える。

## 検証結果

`dataviz` スキルの検証器（OKLab による6検査）を通している。**色を変えたら
必ず通し直す。**

```
node scripts/validate_palette.js "#7096F8,#D2A400,#41C2A8,#A98CE0" --mode light
node scripts/validate_palette.js "#5580FC,#B08A00,#35A98A,#9179DC" --mode dark
```

| 検査 | 明地 | 暗地 |
|---|---|---|
| 明度帯 | PASS | PASS |
| 彩度下限（灰色に見えないか） | PASS | PASS |
| 色覚異常での隣接分離 | **ΔE 11.3**（目標 8 以上） | **ΔE 12.2** |
| 通常視での隣接分離 | **ΔE 18.9**（下限 15） | **ΔE 16.3** |
| 地色とのコントラスト | **WARN**（3:1 未満） | PASS |

> [!WARNING]
> **明地の WARN は無視してよいものではない。**「直接ラベルか表を必ず添える」
> という条件つきで許容される（relief 規則）。本研究の図はすべて直接ラベルを
> 持ち，同じ数値が本文の表にもあるのでこの条件を満たしている。
> **凡例だけに頼る図を作るときは，この配色を使えない。**

落とした候補も記録しておく（同じ失敗を繰り返さないため）。

| 候補 | なぜ落としたか |
|---|---|
| SolidGray を系列色に | 彩度 0 で「灰色に見える」検査に落ちる |
| Yellow 400 `#FFC700` | 明度 0.856 で明度帯（0.43〜0.77）を外れる |
| 珊瑚 `#EE8472` ＋ 緑 `#56C08D` | 色覚異常での分離が ΔE 4.4 で落ちる |
| Blue 1200 を系列色に | 明度 0.221 で暗すぎる。連続値の最濃としてなら使える |

## 使うときの規則

1. **系列色は順に割り当て，使い回さない。**系列が減っても残りを塗り直さない。
2. **色だけで識別させない。**2系列以上なら凡例を置き，4系列までは直接ラベルも付ける。
3. **二重軸は作らない。**尺度が違う2つの量は図を分ける。
4. **連続値は単一色相の明→暗。**虹色にしない。中央に色相を置かない。
5. **文字は文字の色で書く。**系列色で数値やラベルを書かない。
6. **和文を含む図は文字をパスに落とす**（`svg.fonttype="path"`）。
   Typst の SVG 描画は可変フォントを扱えない（[reports/README.md](reports/README.md)）。

## 作図から使う

```python
import sys; sys.path.insert(0, "tools")
from palette import LIGHT, SEQ_BLUE, INK, INK2, GRID, AXIS

ax.plot(x, y, color=LIGHT[0])      # 系列1
ax.plot(x, z, color=LIGHT[1])      # 系列2
ax.grid(color=GRID)
```

実例は [`tools/pathC_figures.py`](../tools/pathC_figures.py)（実験C1 の図5枚）。
