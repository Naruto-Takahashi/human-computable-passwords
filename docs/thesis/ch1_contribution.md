## 中心主張

> HCP に対する勾配学習攻撃の成否は，主に個々の鍵の数字の偏りで決まり，その偏りは学習せずに
> 計算できる量で予測できる。学習攻撃が効く「弱い鍵」は，ランダムに引くと $`N`$ とともに急減し，
> 数字の個数をそろえた鍵では消える。ただし $`f`$ を知る古典的な攻撃は鍵の分布に依らず，
> 学習攻撃より桁違いに少ない観測で鍵を求める。

「弱い鍵」は暗号の読者に通じる言葉で，主張の単位を「関数」から「鍵」に移す。
研究室の系譜はどれも関数ごとに安全性を論じてきたので，これが先行研究との一番大きな違いになる。

## 言わないこと

[../plan.md](../plan.md) §2.3 の表に従う。特に次の2つは緒論で書きたくなるので注意する。

- **「学習による評価では安全性を判断できない」とは書かない。** 学習の失敗を安全の証明にした
  先行研究は少なく（R4 自身が「尚早」と書いている），仮想敵が弱い
- **「鍵の数字をそろえれば安全」とは書かない。** 学習攻撃に限った対策で，ガウス消去には効かず，
  鍵の空間も減る（$`N=30`$ で約 99.7 bit → 81.9 bit）

## 結果による分岐

### C5・C6（介入実験）

| 結果 | 書き方 |
|---|---|
| そろえた鍵が離陸せず，偏った鍵は離陸する | 貢献2をそのまま書く。「数字をそろえる」を学習攻撃への対策として，代償（鍵の空間）と一緒に提示できる |
| そろえた鍵も離陸する | 鍵の偏りは必要条件ではない。貢献1は相関に留め，中心主張を「予測できる」に弱める |
| ランダムな鍵も含めてどれも離陸しない | $`N=30`$ が床。$`N=26`$ で組み直す（[../plan.md](../plan.md) §6） |

### C7（同じ鍵での CNN）

| 結果 | 書き方 |
|---|---|
| CNN は解けない鍵が多く，CNN のばらつきも鍵から来る（$`I_1`$ の高い鍵ほど高い） | 鍵の効き方は学習器によらず，学習器は境目の位置を動かす。先行研究の「$`j`$ 項が壁」は小川らの CNN では当たるが，鍵によっては越える |
| CNN はほぼすべて台地 | 小川らの CNN・この予算では $`j`$ 項を越えない。self-attention の有無を差分として書ける。鍵の効き方は CNN については言わない |
| CNN の多くが中間で止まる | 「壁」とも「解ける」とも書かず，中間の値が $`I_1`$ と予算にどう従うかを書く |
| CNN も同じ鍵で解け，ばらつきは鍵から来る | 先行研究で $`j`$ 項の学習が安定しなかったのは，鍵を毎回作り直したことによる見かけだった。中心主張（鍵が決める）がむしろ強まる。同じステップ数で差があれば「学習器の差は効率の差」と書く |
| CNN も同じ鍵で解けるが，ばらつきは初期値から来る | 学習器の差は無いが，「鍵を作り直したから」とは書かない |

## 先行研究との差分

| 先行研究 | 差分 |
|---|---|
| Murata ら（WISA 2022）・研究室の卒論4本 | 関数ごとに安全性を論じ，実行のたびに鍵を作り直していた。本研究は鍵ごとに離陸率を測り，鍵の性質を特定した。**WISA 版の本文は未入手**で，R4 の卒論との差分を確かめてから書く |
| 小川ら（英語論文の原稿） | 同じ条件の反復で標準偏差が大きいと報告した。本研究はそのばらつきの大半が鍵の違いであることを示す |
| Blocki ら（原論文） | 一様な鍵で $`r(f)=k_2+1`$ 未満の変数が無相関になることを統計的攻撃の下限に使った。本研究は，ランダムな鍵ではこの性質が近似的にしか成り立たず，崩れた分が勾配学習の足がかりになることを示す |
| SGD の学習可能性の理論（Abbe ら・Barak ら） | 低い次数の成分が学習の足場になるという理論と向きが合う。理論の前提とはずれるので，考察で「向き」として述べる |

## 第1章に書く順序（案）

1. **研究背景**: パスワード認証の限界 → HCP の提案 → 原論文の安全性の議論
2. **学習による安全性評価の系譜**: CSP ソルバー → MLP → LSTM → BiLSTM → CNN。どれも $`j`$ 項を学習を難しくする主因とみてきた（R7 の CNN は一部の条件で偶然水準を大きく超えたが，安定しなかった）
3. **問題の所在**: 系譜はどれも関数ごとに安全性を論じ，鍵を毎回作り直していた。鍵ごとの違いは測られていない
4. **本研究の貢献**: 上の表の1〜4（5は1行）
5. **本論文の構成**
