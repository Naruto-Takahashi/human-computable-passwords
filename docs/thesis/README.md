**本文はまだ書かない．** ここに置くのは，章立てと「各章に何を書くか・その根拠は
どこにあるか・まだ足りないものは何か」だけである。

理由は3つ。(1) 実験1〜6 の結論の多くが撤回・保留なので，結果の章は書くたびに
全面改稿になる。(2) 卒論は「捨てる」文書だが，リポジトリの価値は失敗が
残っていることにある。ドキュメント＝下書きにすると，論文に要らないものを
消したくなる圧力がかかる。(3) 運用文書（`make status` の説明など）と論文は
読者も目的も違う。

したがってこのファイルの役目は**下書きではなく，逆算して残タスクを洗い出すこと**である。
本文の執筆は [../plan.md](../plan.md) の第3期（10月下旬〜）から。
