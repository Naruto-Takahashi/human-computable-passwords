## 先行研究の観察を，経路Cの結果で説明する（2026-10-19）

**4本と英語論文は，実行のたびに鍵 $\sigma$ を作り直している**（R5 の実装，R6・R7 の手順，
英語論文の §2「For each run, the secret mapping σ is generated independently」で確認）。
したがって先行研究の結果には，**鍵の違いと初期値の違いが混ざっている。**
経路Cは鍵と初期値を分けて測った（[実験C1・C2・C3](../experiment_index.md)）ので，
先行研究が説明しきれなかった観察を説明できる。

| 先行研究の観察 | 経路Cの結果からの説明 |
|---|---|
| R5: 予測精度が「10%台と90%台の極端な結果しか出ない」 | 離陸は二値で，するかどうかは主に鍵で決まる（C1。$`f_{3,1}`$ では分散の 100% が鍵）。実行ごとに鍵を作り直したので二峰に分かれた |
| R7・英語論文: 同じ条件の反復で標準偏差が大きい（$`f_{2,2}`$・$`N=26`$ で 0.2872±0.1651，最大 68.58%） | ばらつきの大半は鍵の違い。鍵と初期値を分けていないので，「その鍵が易しい」のか「その初期値が当たり」なのか区別できない |
| R4・R6・R7: $`N=50, 100`$ では訓練データにすら適合しない。R7 は原因を表現能力の不足とみた | **C3: $`N \approx 100`$ の壁は鍵の分布の側。**ランダムな鍵は $`N`$ が大きいほど数字が均等になり，学習の足がかりになる1変数の相関が消える。C1-N100 では容量（$`d_{model}`$）・学習率・warmup のどれを上げても改善しなかった |
| R7: $`f_{1,3}`$ は $`f_{2,2}`$ より安全な可能性 | C1 では $`N=26`$・5万件で $`f_{1,3}`$ も 11/20 が離陸する。R7 の低さには学習器と予算の影響が大きい。ただし C3 では $`f_{1,3}`$ だけ $`N`$ を増やした効果が残った。$`N`$ に対する弱さの差は実在しうる |
| 英語論文: $`j`$ 項を除くと学習できる → $`j`$ 項が耐性の主な原因 | Transformer は $`N=26`$ なら $`j`$ 項を解く（C1）。$`j`$ 項は CNN にとっての壁であり，self-attention では外れる。英語論文 §5.4 が将来課題に挙げた「attention・Transformer 系で試す」に経路Cが当たる |

## 評価手順の突き合わせ（2026-09-23，原典を通読して追記）

> [!IMPORTANT]
> **2026-09 まで，本研究は「先行研究は正解率が偶然水準付近なら安全と読んできた」と
> 記述してきたが，原典の手順を確認せずに書いていた。**通読した結果，この記述は
> R4・R5 には当たるが **R7（直前の研究）には当たらない**ことが分かった。
> 以降，先行研究を批判する前に原典の手順を確認すること。

| | 学習器 | $`n`$ | データ数 | 測り方 | 最高精度 |
|---|---|---|---|---|---|
| R4 村田 | MLP | 26,30,50,100 | 1000〜100,000 | 点推定 | 線形関数で **80%** |
| R5 丸野 | LSTM | 100 | 10,000〜100,000 | 点推定 | 3項固定和 $`g`$ で **98.6%** |
| R6 池田 | 埋込+BiLSTM | 26,50,100 | 1000〜50,000 | 点推定 | LSTM 最良で **55%** |
| R7 小川 | 埋込+CNN | 26,50,100 | 1000〜50,000 | **エポック全体の最大値＋反復実行** | $`N=26`$ で **60.84%** |

**R7 の手順は 2026-08 以前の本研究より注意深い。**英語論文版では各 run の最大値を
取って反復し，平均±標準偏差と最大値を報告し，「最大値は攻撃の上限として意味があるが，
典型的な性能と解釈してはならない」と明記している。

### 訓練データにすら適合していない条件がある

R4（$`n=100`$・10万件で訓練データの予測精度 0.21 程度）と R7（$`N=50, 100`$・5万件で
「訓練データに対する学習すら進まない」）は，**学習器が訓練データに適合できていない**。
この条件からは対象の関数について何も言えず，方式の安全性の証拠にはならない。
R7 は考察でこれを表現能力の不足として課題に挙げながら，結論では同じ失敗を根拠に
$`f_{1,3}`$ 型の方が安全だと述べている。**矛盾は R7 の内部にある。**

### 高い精度が出た条件が結論から落ちている

R4 の線形 80%，R5 の $`g`$ 98.6%，R6 の 55%，R7 の 60.84%。
**安全性評価では最良の攻撃者が基準になる**はずで，ここは議論の余地がある。

### その他

- R5 の 4.3 節（$`n=100`$ で，間接参照を残して項を2個に減らしても 16%）は，
  本研究が鍵4マスで得た「動的3項が学習でき，静的5項が失敗する」と順序が逆であり，
  間接参照の難しさが鍵サイズに依存することを示唆する。
- R5 は今後の課題に「予測精度が 40〜50% になる関数・写像の範囲を求める」を挙げている。
  経路Cの「どの鍵なら離陸するか」（C2・C2.1・C3）は，これに答える方向の研究でもある。
- R4 の概要によれば，CSP ソルバーによる先行評価は「記憶する画像が50枚以下なら解読可能」。
  原論文も $`n=26`$ は安全でないと注意している。$`N=26`$ の結果は「安全な設定の再現」ではなく，
  学習可能性を測るための難易度の設定として扱う。

## 本研究の位置づけ（第1章の素材）

1. **学習器の系譜の5代目**（MLP → LSTM → 埋め込み+BiLSTM → 埋め込み+CNN → Transformer）。
   先行研究で初めて，$`j`$ 項を含む $`f_{k_1,k_2}`$ を解く学習器を示した（$`N=26`$）。
2. **先行研究に混ざっていた「鍵の違い」を取り出した。**離陸を決めるのは鍵の数字の偏りであり，
   $`N`$ を大きくすると学習が効かなくなるのは，記号の数ではなく鍵の分布の側の理由による（C3）。
   R7 が今後の課題に残した「学習器の能力不足と課題の難しさの切り分け」に答える。
3. **測定系そのものを問題にした**（評価件数・鍵の引き・学習予算・run のばらつき。実験2・5b・7）。
   R7 の ±0.1651 は，同じ問題が先行研究にもあったことを示す。

経路A（in-context 推論）・経路B（微調整）は事前学習済みの LLM を使う別の系統である
（[../plan.md](../plan.md) §1.3.1）。
